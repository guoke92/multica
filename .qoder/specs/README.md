# 协作群（Room）设计规范

**唯一权威蓝本：** [`room-ui-design.canvas.tsx`](./room-ui-design.canvas.tsx)

- 产品 UI/UX、消息引用、结构化 @、Assignment 指派、Invocation 执行态、Manager 决策、流程动态、人工确认、前后端 API/WS 契约，**仅**以此文件为准。
- **禁止**在 `.qoder/specs/`、`docs/` 或任务文档中另写平行的 Room 实施方案、路由监督清单、实现差距对照表。
- 工程任务从 canvas 内「验收清单」Tab 拆解；争议以「设计宪法」裁决。
- 与 Issue 工作区**无自动桥接**；群内交付以 Message / Mention / Assignment / Invocation / ManagerDecision / InvocationEvent 自闭环。

在 Cursor 中打开 `room-ui-design.canvas.tsx` 审阅交互线框与各 Tab 说明。
